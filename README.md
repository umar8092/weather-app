# Weather App

A free weather forecast for any city or your current location, with advice (umbrella? what to wear?), hourly and 7-day forecasts. No sign-up and no API key.

**This project now lives in the [apps repository](https://github.com/umar8092/apps/tree/main/weather-app).** Live app: https://umar8092.github.io/apps/weather-app/
