# Weather App

Type a city and see its current temperature, conditions, humidity and wind speed. Built with plain HTML, CSS and JavaScript, using the [OpenWeatherMap](https://openweathermap.org/api) API.

**Live demo:** https://umar8092.github.io/weather-app/ (shows a prompt until an API key is added, see below)

## Set it up

1. Get a free API key at https://openweathermap.org/api (new keys can take up to a couple of hours to activate).
2. Open `script.js` and replace `YOUR_API_KEY` with your key.
3. Open `index.html` in a browser.

```
git clone https://github.com/umar8092/weather-app.git
```

Never publish your own key in a public repo. For a public site, keep it on a small server instead.
